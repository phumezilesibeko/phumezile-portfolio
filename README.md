# Phumezile Sibeko Portfolio

Vue 3 single-page portfolio built with Vite.

## Run locally

In PowerShell, run:

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local URL printed by Vite. To create a production build, run `npm.cmd run build`.

Project cards are data driven in `src/data.js`; reusable card components are in `src/components/`.

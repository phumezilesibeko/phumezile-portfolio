To add your images, drag or copy the image files into this `images` folder in the VS Code Explorer, then use these filenames:

- `phumezile.jpg` — profile photo
- `artisan-hub.png` — e-commerce project screenshot
- `artisan-hub-2.png` — second e-commerce screenshot
- `hr-system.png` — HR system project screenshot
- `hr-system-2.png` — second HR system screenshot

Each project screenshot is shown in its own card in the Projects section. The hero still features one Artisan Hub card and one HR card. If an image has a different extension, either rename/convert it to the extension above or update its import in `src/data.js` (the profile photo import is in `src/App.vue`).
